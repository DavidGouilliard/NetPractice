## Description

This project focuses on understanding and mastering **networking fundamentals** through the NetPractice training interface.

The goal is to practice core concepts such as TCP/IP addressing, subnet masks, routing, and the OSI model in a practical, problem-solving environment. Each level requires configuring a virtual network correctly so that all hosts can communicate as expected.

---

## Instructions

### Running NetPractice

1. Open the NetPractice training interface by opening the provided `index.html` file in your web browser (Chrome and Brave work, not Firefox).
2. Complete each level by configuring IP addresses, subnet masks, and routing elements correctly.

### Exporting configurations

* Once a level is completed, **export the configuration** using the interface export option.
* The export generates a configuration file corresponding to the completed level.

### Submission requirements

* You must export **10 configuration files**, one for each level.
* All exported files must be placed **at the root of the Git repository**.

## Resources

This section lists references used to study the networking concepts required for NetPractice, as well as how AI tools were used during the project.

### Networking concepts studied

* TCP/IP (Transmission Control Protocol/Internet Protocol) addressing
* IPv4 and IPv6
* Subnet masks and CIDR (Classless Inter-Domain Routing) notation
* Network, broadcast, and host addresses
* Default gateway
* Routers and switches
* OSI (Open Systems Interconnection) model
